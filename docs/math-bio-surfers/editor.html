Update the online game

  1. Finish your edits and select Download questions.json.
  2. Open the upload page below. Upload that file with the name questions.json, replacing the existing file.
  3. Select Commit changes in GitHub. Wait for Pages to deploy, then refresh the game.
Upload questions to GitHub ↗

GitHub controls who can publish. Visiting this editor does not grant permission to update the game.

For an offline copy, use Download updated game. No code editing or Python build is needed.

Use normal mathematical text such as u̇, λ, u² and ∂u/∂t. The game displays text directly, so LaTeX commands are not rendered. Keep at least 12 questions, one procedure and one misconception per level.
